# CHECKMATE — 주시원 포트폴리오

UX/UI · 서비스 기획자 주시원의 포트폴리오 웹사이트입니다.

## 구성

| 파일 | 화면 |
|---|---|
| `index.html` | 메인 — 히어로 · HOW I PLAY · MAIN PROJECTS · ABOUT |
| `projects.html` | 프로젝트 목록 — 유형 · 산출물 필터, 정렬 |
| `project-detail.html` | 프로젝트 상세 — `?project=<id>` 로 5개 프로젝트 |
| `about.html` | 소개 — 프로필 · 일하는 방식 · 학력 · 수상 · 역량 · 연락처 |

빌드 도구 없이 HTML · CSS · JavaScript 로만 만들었습니다. 서체는 `fonts/` 의 Pretendard Variable 을 직접 담고 있어 외부 요청이 없습니다.

## 로컬에서 보기

폴더를 받아 `index.html` 을 브라우저로 열면 됩니다.
